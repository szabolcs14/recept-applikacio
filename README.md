# Vue Receptgyűjtemény Projekt
Kétfős csapatprojekt Vue.js 3 és Bootstrap használatával. Az alkalmazás célja receptek listázása, keresése, szűrése, rendezése és új receptek felvétele LocalStorage tárolással.

## Feladatok

### "A" Csapattag – UI/UX Specialista
- [ ] Navigation bar kialakítása Bootstrap elemekkel
- [ ] RecipeCard komponens létrehozása, stílusozása és hover effektek
- [ ] Placeholder képek beállítása
- [ ] Receptek reszponzív rács elrendezésének kialakítása
- [ ] Keresősáv, szűrők és "Nincs találat" üzenet vizuális megvalósítása
- [ ] Új recept űrlap dizájnja (mobile-first, akadálymentes elemek)
- [ ] Form validáció és sikeres/sikertelen művelet visszajelzések stílusozása

### "B" Csapattag – Logika és Adatkezelés Specialista
- [ ] Dummy adatok létrehozása
- [ ] Props és emit események beállítása
- [ ] RecipeCard logika és eseménykezelők bekötése
- [ ] Keresés, szűrés és rendezés megvalósítása computed properties segítségével
- [ ] Form validáció implementálása
- [ ] Új recept hozzáadása funkció
- [ ] LocalStorage kezelés és hibakezelés beállítása
